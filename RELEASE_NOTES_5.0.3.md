# ToolRecap V5.0.3

- Places automatic V5 output inside the selected source folder.
- Names automatic output from the source folder rather than the final episode filename.
- Example: `D:\1.TVShows\Marshals` publishes to `D:\1.TVShows\Marshals\Output_Marshals_Highlight` or `Output_Marshals_Recap`.
- Example: `D:\Yellowstone (2018)\S04` publishes to `D:\Yellowstone (2018)\S04\Output_S04_Highlight` or `Output_S04_Recap`.
- Preserves an explicitly configured manual output directory without modification.
