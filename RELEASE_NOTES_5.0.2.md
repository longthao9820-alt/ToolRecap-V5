# ToolRecap V5.0.2

- Shows episode rows incrementally while a Recap or Highlight folder is being scanned.
- Reports source discovery progress, elapsed time, current file, and recent events in **Real-Time Status / Activity**.
- Enables **Create Highlights** immediately after the completed source list is applied to the UI.
- Prevents delayed saved-project status from overwriting an active or newly completed source scan.
- Logs unexpected background-message dispatch failures instead of silently leaving the UI in a stale state.
